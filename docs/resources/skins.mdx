# Voice agent skins and orb UI themes

Skins are a product direction for orb-ui: reusable visual treatments for voice agents that can carry a product's brand and personality while keeping the same underlying state model.

## What a skin should include

A useful skin should define:

- visual theme
- motion behavior
- color tokens
- state mapping
- size behavior
- accessibility constraints

## Provider-agnostic by design

Skins should work across Vapi, ElevenLabs, OpenAI Realtime, Gemini Live API, and custom stacks. The provider should supply state and volume. The skin should decide how those states feel visually.

## Roadmap

The right order is:

1. Ship more polished built-in themes.
2. Document the theme API.
3. Add a gallery of presets.
4. Consider community submissions after there is visible usage.

Marketplace mechanics should come after the theme system proves useful.
